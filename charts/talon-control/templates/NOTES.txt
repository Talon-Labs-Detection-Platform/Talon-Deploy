{{- if .Values.config.labsUrl }}

{{- if not .Values.config.trustProxy }}

Set config.trustProxy=true when the app sits behind an ingress.

{{- else }}

default origin (https://talon.studio) — unless an admin has saved a website
under Settings -> Company, which wins over both. Set either for the
Marketing -> Traffic page to record pageviews.
