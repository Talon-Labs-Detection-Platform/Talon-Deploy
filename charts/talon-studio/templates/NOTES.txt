Talon Studio has been installed.

If ingress is disabled, port-forward the app:

  kubectl port-forward svc/{{ include "talon-studio.fullname" . }} 3000:{{ .Values.service.port }}

Then open:

  http://localhost:3000

First sign-in: {{ .Values.secrets.adminUsername }} (or {{ .Values.secrets.adminEmail }}).
{{- if .Values.secrets.adminPassword }}
The password is the one you set in secrets.adminPassword.
{{- else }}
The password is generated on first boot, printed once in the pod log and saved
on the data volume. Read it with:

  kubectl exec deploy/{{ include "talon-studio.fullname" . }} -- cat /data/secrets/initial-admin.txt

You must change it at first sign-in.
{{- end }}

Secrets left empty in values are generated on first boot into /data/secrets on
the data volume. Back up /data/secrets/encryption_key: stored credentials
cannot be decrypted without it.
